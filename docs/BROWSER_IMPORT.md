# 从 Chrome / Edge 导入画廊登录

网页登录不会自动把 Cookie 交给下载助手。此功能需要安装配套的“画廊登录导入”扩展，然后在扩展里主动点击发送。

## 首次安装，只需一次

1. 在 Chrome 地址栏输入 `chrome://extensions/`，按回车；Edge 使用 `edge://extensions/`。
2. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择下载助手 EXE 旁边的 `BrowserExtension` 文件夹。选择文件夹本身，不是里面的文件。
4. 点击浏览器右上角的拼图图标，将“画廊登录导入”固定到工具栏。

软件里的“设置 → ExHentai 登录 → 安装 / 使用说明”提供扩展文件夹的完整路径和复制按钮。软件 1.1.8 配套扩展为 1.2.2，也兼容软件 1.1.7。扩展可以独立更新：更新文件后，请在扩展管理页点击该扩展的刷新按钮，并确认画廊域名的 HTTP / HTTPS 站点权限。重新打开扩展，顶部应显示“扩展 1.2.2”。

## 每次导入

1. 在同一个 Chrome / Edge 用户中打开要下载的画廊，确认可以看到内容。下载 ExHentai 时请在 ExHentai 页面操作。
2. 在下载助手点“开始接收 Cookie”，再点说明窗口的“开始等待浏览器”。软件现在等待五分钟。
3. 切回已登录的画廊网页，点击工具栏的“画廊登录导入”，再点“发送到下载助手”。
4. 返回下载助手查看验证结果。只有表站通过时，仍不能保证里站可以下载。
5. 验证通过后，回下载中心点“继续下载”。

## 按当前提示处理

| 提示 | 下一步 |
| --- | --- |
| 软件“尚未连接扩展” | 确认扩展已安装，再到画廊网页打开扩展并点击发送。 |
| 扩展“没有连上下载助手” | 如果软件明明在倒计时，请确认软件为 1.1.6 或更新版本；旧版会误拒绝某些 Chrome / Edge 扩展连接。更新后重新开始接收，再在扩展点击发送，已有扩展无需重装。 |
| “当前 Chrome 用户中没有完整的画廊登录信息” | 这是旧版扩展的提示。先在扩展管理页刷新到 1.2.2 并确认站点权限，再发送；旧版可能漏读未标记 Secure、论坛子域、非首页路径或页面分区里的 Cookie。 |
| “扩展没有读到配对的账号 Cookie” | 点击“检查 Cookie 读取（不发送）”，查看两站各字段是否读到。先核对扩展版本和站点权限；缺少字段不代表没有登录。若仍缺失，在同一窗口打开 E-Hentai 的 My Home 或论坛核对网站账号。 |
| “扩展缺少站点访问权限” | 在扩展详情中确认已允许本扩展访问 E-Hentai / ExHentai；账号登录和扩展站点权限是两项独立设置。 |
| Cookie-Editor 能看到三个登录字段，本扩展却全部显示未读到 | 刷新到扩展 1.2.2，确认已授予画廊域名的 HTTP / HTTPS 权限。Chrome 会用 HTTP 权限检查未标记 Secure 的 Cookie，缺少该权限时会静默返回空列表。软件 1.1.7 无需重装。 |
| 字段“已找到但值为空” | 名称存在，但浏览器没有返回可用值；这与字段不存在不同。记录读取状态，检查浏览器 Cookie 读取问题。 |
| “缺少有效 igneous” | 打开并刷新 ExHentai，确认能看到内容后再发送；若仍是空白页，检查账号权限。 |
| “已接收，正在验证” | Cookie 已经送达，等待网站验证结果；不要重复发送。 |
| “E-Hentai 有效、ExHentai 未通过” | 从能正常打开画廊的 ExHentai 网页重新发送；检查账号是否有该画廊的查看权限。 |

扩展只读取画廊网站的三项必要 Cookie，不读取密码或浏览记录。Cookie 交给本机软件后，软件会向相应画廊网站验证登录。
