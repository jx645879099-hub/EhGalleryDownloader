# 使用指南

## 登录

软件支持三种方式：

1. **从当前网页导入**：适合浏览器已经登录但忘记密码的用户。首次使用时加载完整包中的 `BrowserExtension` 文件夹，随后在软件中授权并点击浏览器工具栏的“画廊登录导入”。
2. **手动填写 Cookie**：从浏览器开发者工具的请求标头中复制 `Cookie:` 后的完整内容。
3. **不登录**：只能访问无需登录的内容。

Chrome / Edge 的本地资料可能使用应用绑定加密，因此软件不承诺直接读取浏览器资料一定成功。网页导入和手动方式均不需要关闭浏览器。

## 下载与续传

- 画廊首页链接可以一次粘贴多条，每行一条。
- 中途停止不会删除已经完成的图片，`.part` 文件会保留给下载内核续传。
- 在下载中心选中未完成任务，点击“继续下载”。按钮会立即进入准备状态；准备期间可取消，下载期间可暂停。
- 软件先扫描本地连续的完整图片编号，优先通过最后一张已完成图片的令牌进入断点，再继续第一个缺失页。令牌失效或缺失时会显示兼容续传提示；此时定位旧页可能较慢。
- 如果前 200 张完整，会从第 201 张开始；如果第 57 张缺失，会从第 57 张开始，避免漏图。
- CBZ 任务不会使用快速跳页，因为压缩完成后无法仅凭外部文件准确判断包内缺页。
- 已完成任务默认从主页列表隐藏，并未删除；勾选“显示已完成”或打开“下载记录”即可查看。

ExHentai 对提取请求默认保留安全间隔。快速续传减少的是已完成页面的重复访问，不会通过取消间隔来增加账号被限流的风险。

## Clash 与节点测试

“自动识别端口”会通过 Clash Verge / Mihomo 的本地控制接口读取当前 `mixed-port`。下载、登录验证和更新检查前会重新核对端口。

节点测试开始时，软件会主动要求 Clash 对所选策略组发起本轮检测，不使用面板中可能很久以前留下的延迟。第一阶段剔除无法连接的节点，第二阶段使用真实画廊图片小流量测速。

排序优先级为：

1. 完整传输成功率
2. 中断次数
3. 实际下载速度
4. Clash 延迟

测试结束或停止时会恢复原节点；异常退出留下的恢复记录会在下次启动时处理。

## 图片质量

- **原图**：画质最好，流量较大，并受网站图片额度 / GP 规则影响。
- **压缩图**：使用网站提供的压缩版本，通常更省流量。
- 原图额度不足时，可以按设置回退到网站压缩图。

## 本机数据

设置、任务队列和运行日志默认保存在：

```text
%LOCALAPPDATA%\EhGalleryDownloader
```

详细说明见 [隐私与数据说明](PRIVACY.md)。
