画廊登录导入扩展 1.2.2（Chrome / Edge 通用）

首次安装：
1. Chrome 打开 chrome://extensions/；Edge 打开 edge://extensions/。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件所在的 BrowserExtension 文件夹。
5. 建议将“画廊登录导入”固定到浏览器工具栏。

以后使用：
1. 保持已登录的 E-Hentai / ExHentai 网页打开。
2. 在画廊下载助手的“设置 → ExHentai 登录”中点击“开始接收 Cookie”，然后点击说明窗口里的“开始等待浏览器”。
3. 在五分钟内回到已登录的画廊网页，点击浏览器工具栏的“画廊登录导入”，再点击“发送到下载助手”。
4. 返回软件查看验证结果。已发送不等于登录已验证；E-Hentai 通过也不代表 ExHentai 通过。

常见问题：
- 只在网页登录不会自动导入，必须安装本扩展并点击发送。
- 看不到扩展图标：点击 Chrome / Edge 右上角的拼图图标，固定“画廊登录导入”。
- 扩展提示没有连上下载助手：重新在软件中开始接收，再到扩展发送。
- 下载 ExHentai：先在同一浏览器用户中打开 ExHentai 并看到内容，再发送；只有表站或论坛登录可能不够。
- 扩展更新后，必须在扩展管理页点击该扩展的刷新按钮；重新打开扩展，顶部应显示“扩展 1.2.2”。本次需授予 E-Hentai / ExHentai 的 HTTP 和 HTTPS 站点权限，用于读取没有 Secure 标记的登录 Cookie。
- 提示没有读到账号 Cookie：点击“检查 Cookie 读取（不发送）”，分别查看账号编号、登录凭证和里站凭证是否读到；这不能直接判断网站是否已登录。
- 1.2.0 会读取画廊域名及其论坛子域、不同路径与当前页面分区的必要 Cookie，不会扫描其他 Chrome 用户或其他网站。
- 1.2.1 优先使用与 Cookie-Editor 相同的当前网页直接读取方式，兼容按域名和指定存储查询为空的情况；诊断会显示当前网页读取到的 Cookie 数量，并区分字段不存在和值为空。
- 1.2.2 补齐画廊域名的 HTTP Cookie 读取权限。Chrome 按 Cookie 自身的 Secure 标记核对权限；未标记 Secure 的 Cookie 即使在 HTTPS 网页使用，也需要对应域名的 HTTP 权限。

扩展只读取上述两个网站的 ipb_member_id、ipb_pass_hash、igneous，
并且只发送到本机 127.0.0.1。它不会读取浏览器保存的密码、历史记录或其他网站。
